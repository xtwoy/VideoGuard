## 1. 两分钟项目背景

我们选题为**短视频内容安全辅助审核**，面向真人拍摄与AI生成视频，不限未成年人内容。

希望实现：视频上传后，视频解析阶段理解画面、声音和字幕；问题定位/关系判断阶段辅助识别危险动作与鼓励/警示的关系；**我们自主编写的PEAD规则引擎**检查证据引用和关系、处理分歧和人工复核；问题汇总阶段生成原因与修改建议；前端展示时间位置并导出HTML审核报告。

**团队原创工作：** PEAD证据关联/约束、审核分流、程序实现与实验评估。  
**可替换外部能力：** 视频解析、关系判断、问题汇总。  
**名称约定：** 外部能力只能按职责命名；PEAD才是团队的Python审核引擎。

## 持续开发规约

1. 新协议、新字段或新阶段替代旧设计时，直接删除旧实现、旧 fixture、旧测试和旧环境变量，不新增“兼容旧版”的回退分支。
2. 供应商、模型名、SDK 名只能存在于当前部署配置，不能成为流程、数据协议、用户报告或模块命名。
3. 每次协议变更必须同时更新 Prompt、运行时校验、fixture、单元测试和开发文档；任何一项未完成不得宣称迁移完成。

## 3. 已完成与未完成的真实边界

### 已有原型代码
- `frontend/app/page.tsx`、`app/layout.tsx`、`app/globals.css`：Next.js 16 App Router 前端，采用 React 19、严格 TypeScript 与 Tailwind CSS 4，支持预览/结果/点击时间/报告下载；
- `backend/main.py`：FastAPI接口、上传校验、异常与授权校验；
- `backend/pipeline.py`：视频解析 → 问题定位 → PEAD → 可选关系判断 → 审核报告的审核主线与失败降级；
- `backend/src/pead_engine.py`：自研规则审核；
- `backend/src/issue_locator_client.py`：JEV 原生类型化答案到统一问题定位 JSON 的适配；
- `backend/src/relation_client.py`：可选关系判断适配；
- `backend/src/relation_fusion.py`：关系判断与PEAD结果融合；
- `backend/src/model_gateway.py`：视频解析和审核报告适配；
- `backend/database.py`：SQLite单表；
- `backend/report.py`：可直接打开的HTML报告；
- `backend/tests/test_mvp.py`：MVP后端测试；另有`backend/tests/test_event_audit.py`事件级审计测试。测试数量以当前命令实际输出为准。

### 必须真实补齐
1. **真实视频解析接口联调**：测试一段合法授权、含声音的小型视频，确认`videoguard_video_parse_v2`、shot/事实级时间范围、音视频信息与事实引用；
2. **问题定位接口联调**：确认 JEV 原生回答能被适配为`videoguard_issue_locator_v1`，不会创造事件或事实引用；
3. **关系判断与审核报告接口联调**：确认两者严格使用各自 JSON 协议，且不会自造证据 ID、事实时间或整改动作关联；
4. **真实视频证据核验**：对照回看模型所说的动作、语音和时间点，修复虚假定位；
5. **小型公平对照实验**：A/B/C/D按相同输入和风险定义比较质量、复核量和成本；
6. **最终材料审核**：核对官方提交文件及原创技术披露要求（另由团队安排；本次不写参赛作品报告）。

**不能写成已完成：** 云端模型准确率、真实API全链路测试、PEAD的性能提升。

## 6. 需要团队确认的前置条件

- 当前视频解析/问题汇总服务的`VIDEO_MODEL_API_KEY`、`VIDEO_MODEL_BASE_URL`能否在本地使用；
- 当前关系判断服务的`RELATION_MODEL_API_KEY`、`RELATION_MODEL_ENDPOINT`、`RELATION_MODEL_ID`是否可用，是否允许发送经脱敏文本；
- 是否有足够且合法授权的视频素材；
- 是否有人愿意人工标注正负样本、视频时间位置与传播语境；
- 指导教师和学校内部审核流程是否已安排；
- 参赛作品使用开源依赖及AI辅助开发的说明由谁负责。

## 7. 最容易犯的五个错误

1. **把外部关系判断叫做自研审核引擎**：错误。自研叫PEAD。
2. **把API串联叫原创算法**：错误。必须证明证据约束比无约束方法有用。
3. **把问题汇总输出作为真实事实**：错误。只允许引用已检查的证据，且需要人工核实原视频。
4. **把全部样本转人工后宣称零误报**：错误。必须同步报告人工复核率和自动处理覆盖度。
5. **仅凭政策文件就说系统必然合规有效**：错误。政策说明治理背景，不替代技术实测。

> **严禁重新设计微服务、React工程、复杂数据库，也不要写参赛作品报告。** 我们只沿一条主线推进：上传真实授权短视频→视频解析→可选关系判断→PEAD证据约束→问题汇总与编辑建议→SQLite→HTML报告。

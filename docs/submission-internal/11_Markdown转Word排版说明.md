# 独立提交文档的 Word / PDF 排版说明

本次分别导出作品简介、设计方案、作品测试与分析、创新性说明。原 `docs/10_参赛作品报告.md` 仅作内部合订参考，**不作为额外提交文件导出**。

## 一、正式正文来源

| 导出文件类别 | Markdown 正文来源 |
|---|---|
| 作品简介 | `../submission/01_作品简介.md` |
| 设计方案 | `../submission/02_设计方案.md` |
| 测试报告（作品测试与分析） | `../submission/03_作品测试与分析.md` |
| 创新性说明（其他文档） | `../submission/04_创新性说明.md` |

其他文档中的运行说明按实际需要另行整理。原创性声明使用官方模板独立填写；重大改进说明按参赛情况确认。目录、检查清单与制作规范均为内部材料，不自动纳入提交包。

官方通知及来源见 `13_创意作品赛提交要求核对.md`。最终文件名按队长姓名、作品名称及资料名称组合，正文保持匿名。

## 二、版式与标题

统一参考作品报告模板的 A4、宋体小四、1.5 倍行距制作，以保持各文档风格一致。独立文档按自身内容组织，不套用五章合订目录。

| Markdown | Word 样式 | 建议 |
|---|---|---|
| `# 视鉴 VideoGuard-E：……` | 文档标题 | 每份文档独立封面或标题区 |
| `## 一、……` 或 `## 1. ……` | 标题 1 | 各文档自行编号 |
| `### 1.1 ……` | 标题 2 | 小四加粗 |
| 正文 | 正文 | 宋体小四、1.5 倍行距 |

设计方案与测试报告可使用 Word 自动目录，分别更新页码。作品简介与创新性说明按篇幅决定是否设置目录。作品报告模板的摘要 500 字要求不机械套为每份独立文件的总字数限制。

## 四、A/B 对照的排版

图旁保留加粗说明“**两组动作画面相同，变化的是后续口播**”。每组口播原句放在对应图片上方，PEAD 判断依据及结果放在下方，不向配图叠加字幕。

并排时用两列表格承载口播、图片、判断依据和结果。不得因分页将口播说明与对应图片拆开。

## 五、表格、代码和引用

- 表格首行设置跨页重复；同一图块或短表行避免跨页拆分。
- 表格、代码块与行内代码保持宋体小四，按模板风格统一；代码中的标识、引号与命令内容原样保留。
- 各文档的标题、图号、交叉引用独立核对，不保留指向合订稿章节或附录的悬空引用。
- 创新性说明的参考文献独立编号，与正文引用对应。
- 方法与验证范围集中在测试报告中说明；图注使用正文已确认的简短版本。

## 六、导出与匿名检查

- 四份正文分别导出 PDF，不额外导出内部合订稿。
- 按官方通知控制 PDF 大小不超过 10M；公开通知未列页数上限，平台若有新增限制再对应处理。
- 文件命名与正文匿名分别检查：文件按报名信息命名，正文不出现学校、院系、导师或成员身份。
- 检查封面、批注、修订记录、文档作者及 PDF 元数据。
- 在实际阅读尺寸查看图片、表格和中文字体；确认无拉伸、越界、缺字和乱码。
- 单独检查原创性声明的填写、签名与导出状态。

最终提交文件与程序交付包逐项对应材料目录，保留文件摘要与上传回执。各份 Markdown 当前为独立源稿，最终 PDF 仍需导出后验收。

# 创意作品赛：官方提交要求与材料对应

核对日期：2026-10-21。适用赛道为“（一）揭榜挑战赛与创意作品赛”中的**创意作品赛**，作品方向为内容安全。

依据：[第五届大赛邀请函](https://cpipc.acge.org.cn/cw/contestNews/detail/2c90800c8093eef401809d33b36f0652/2c9080199ed8b78d019ed96ceea21560?page=0)中的“五、参赛要求（一）”及[附件 2：作品相关模板](https://cpipc.acge.org.cn/sysFile/downFile.do?fileId=dc0d4965d508456db60ab9464d39b476)。本文件用于内部核对，不作为作品正文提交。

## 一、官方要求摘要

| 项目 | 通知要求 |
|---|---|
| 资料范围 | 包括作品简介、设计方案、测试报告、其他文档、参赛作品声明，并提供可执行程序 |
| 文档格式与大小 | PDF，通知标明不超过 10M |
| 文件命名 | 按队长姓名、作品名称、资料名称组合 |
| 匿名 | 作品正文、展示及说明材料避免出现影响公平的院校、导师等身份信息 |
| 原创与重复参赛 | 独立原创；重复参赛的适用情形需核对，重大改进说明按要求另交 |
| 本通知提交截止 | 2026-10-22 23:59 |

通知列出了资料类别，没有在公开页面逐项展示平台上传栏位。**按用户确认，分别准备各份文档**；上传时再对应平台栏位，不将一份五章报告视为已覆盖全部提交项。

文件命名条款的后半句另提高校名称，与前面的命名组合不完全一致。本套材料按明确列出的组合准备，实际导出命名以提交系统字段为准；正文匿名与文件命名分别检查。PDF 准备时各份控制在 10M 内，平台是否另有总量限制在上传时核对。

| 提交材料 | 独立正文来源 | 准备方式 |

## 三、附件 2 的核对结果

附件 2 包含三份模板：作品报告、作品原创性声明、作品重大改进说明。已对下载文件与仓库现有三份 `.doc` 逐一比对，文件内容摘要一致。

作品报告模板提供摘要、五章正文与参考文献结构，未要求附录。本次按用户确认的分开提交方式整理四份独立材料；创新性说明归入“其他文档”，并非将其另称为公告中的必交类别。原 `docs/10_参赛作品报告.md` 仅作内部合订参考，**不额外加入本次提交包**。公开通知未逐项展示上传栏位，平台如另有必填项目，按该项目实际要求处理。

## 四、提交状态与待补项

- 四份独立正文已按作品简介、设计方案、作品测试与分析、创新性说明分别整理。
- 已确认的界面图、论证图和口播对照说明分别纳入设计方案与测试报告；合订稿仅内部保留。
- 原创性声明签名、是否需要重大改进说明及最终文件命名，需团队实际填写或确认。
- 可执行程序交付包及最终版本的目标环境验收尚需完成，现有源码与开发启动记录不视为打包交付完成。
- 最终导出的 PDF 仍需逐份检查大小、字体、匿名、图片清晰度和链接；本轮未生成最终 PDF。

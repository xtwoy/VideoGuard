当前实际运行依赖 PyArg、NetworkX 与 Pydantic，已加入依赖清单和锁文件。Argdown、OPA 与 SafeWatch 仍只是参考，没有接入其运行引擎；没有复制这些项目的源码为自研文件。
Grounded 语义是已有标准方法，不能称为本队首次提出。团队实现工作的重点是：视频风险证据建图、规则映射、来源合并、事件隔离、报告与可复现评测。

## 从规则条件到可检查的论证

1. **证据来源投影**：问题定位引用的 `SHOT_ID:FACT_ID`、事件与定位质量进入 PEAD 观察。
2. **同源合并**：来源引用、标签、模态、事件和时间完全相同的线索归为同一命题，保留所有原始 ID 的别名。重复描述不会增加票数或形成独立观察。来源未知时不根据文字相似度擅自合并。
3. **按动作与事件建图**：为动作＋鼓励构造支持论证，为同一动作的警示构造反向论证，为不可靠时间、未核验关系、未知指向构造信息缺口。模型关系回答引用同一批观察，不属于独立事实证据。
4. **论证裁决**：反向语境与鼓励论证相互攻击；明确事件指向冲突会质疑模型关系推断。没有被反驳且能被保守接受的论证才支持强提示，相互攻击无法裁决时保留人工复核。
5. **事件独立聚合**：每个事件记录自己的判断与处置；一段安全教育不能消除另一段已支持的危险诱导。针对另一句话的“无关”关系不会反驳已有独立支持，但相关警示和不充分关系仍可要求复核。
6. **解释输出**：保存论证前提、原始事实引用、攻击边、接受／驳回／未决标签、攻击与防御依据、命中规则和规则指纹、逐事件结论，以及被采纳支持论证的前提集合。
7. **证据移除检验**：最多检查部分关键观察，移除同源命题时同时移除其别名，复用冻结的证据 ID 对与模型回答，不重新编号或调用模型。报告明确说明覆盖是否截断；这不是视频剪辑后的重新识别，也不是因果证明。

前提集合是某条论证的依据，不宣称已求得所有证据组合上的全局最小解释。
当前可信门限保持已有配置，没有把外部模型概率相加，也没有产生未经校准的审核准确率或风险概率。

## 已修复的语义反例

`relation_wrong_encouragement` 的输入保持“动作＋显式警示，模型却回答鼓励”。旧版输出 `SUPPORTED/FLAG`；新图引擎输出 `CONFLICTED/REVIEW`。
用例、回归预期、生成报告和真值表已同步更新，明确记录为修复。它表示程序会处理已提供的冲突，不表示已证明原视频理解正确。

剩余边界：如果上游根本没有报告警示、时间或事件指向错误，图引擎无法凭空得到正确事实；对应守护测试保留。正常风险识别仍需要真实视频联调与评估才能判断。

## 核心代码与输出

- `backend/src/argumentation.py`：PyArg 求解适配、NetworkX 循环诊断及标签解释。
- `backend/src/evidence_graph.py`：风险建图、来源合并、事件裁决、证据前提和移除检验。
- `backend/src/pead_engine.py`：规则遍历与事件记录，危险诱导规则进入图引擎。
- `backend/src/relation_fusion.py`：将经过可信门限的模型回答作为图中论证，替代原有单独融合条件分支。
- `backend/pipeline.py`：保存 `pead_audit`；报告模型只获得精简后的事件结果，完整图留在本地结果中。
- `backend/report.py`：HTML 中新增“证据论证与裁决”及“证据移除检验”，所有模型字段进行 HTML 转义。
- `backend/tests/test_evidence_graph.py`：独立语义核对、来源别名、事件隔离、定位门限、错误与解释守护。

对照入口仍为 `python -m fixtures.compare_pead --write`。两组使用相同输入，控制组也有校验与保守复核。
新结果及冻结输入在 `backend/reports/mock-pead-comparison.*` 与 `mock-pead-inputs.json`。
可直接打开 `backend/reports/pead-graph-demo.html` 和 `pead-graph-warning-regression.html` 查看合成审核报告。

## 验证方式与主张范围

论证内核通过穷举三节点的所有攻击图，与独立枚举 complete extensions 后求交集的结果核对；包括自攻击、互攻、无攻击与防御链。
这验证的是有限测试范围内的逻辑内核，不是所有图规模上的形式化证明。
现有合成样例、关系回答组合、HTTP 失败路径、HTML 转义和同输入对照一起复跑。本轮实际数量与环境信息见 `backend/reports/pead-upgrade-validation.json`；`mock-validation-summary.json` 是上一轮记录。
前端源码未修改；此前生产构建的沙盒内存读取限制仍未解除。此次仍未调用真实模型。

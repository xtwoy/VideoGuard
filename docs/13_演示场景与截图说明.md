# 演示场景与截图说明

整理日期：2026-10-17。已有 18 套 fixture 中选出 8 个演示场景，复用冻结的模型形状输入；正式 `_run_models` 编排执行 PEAD、PyArg 求解、关系门控和报告校验，结果通过 SQLite 保存为 `DEMO`。

## 打开方式

- 交互工作台：启动服务后访问 `http://127.0.0.1:5173`，在“演示场景”选择案例，点击“运行合成场景演示”。无需选择视频或填写模型密钥。
- 离线演示包：打开 `backend/reports/demo-showcase/index.html`，查看 8 份报告、8 张截图和完整攻防页面。整个目录可以复制到其他电脑。
- 报告截图：`docs/assets/demo/`；主要四张已插入 `docs/10_参赛作品报告.md`。
- 原始输出与来源：`backend/reports/demo-showcase/records.json` 保存本次 HTTP 返回记录，`manifest.json` 保存场景、截图来源 URL 与 SHA-256。每条结果的 `meta.fixture_sha256` 记录所用输入文件摘要。

页面截图由 Chrome 无头命令行真实渲染，使用生产前端和 HTTP API，无 WebSocket、无浏览器调试端口。Mock 场景未关联原视频，回看按钮禁用；截图不证明真实视频识别或播放链路已经验证。

## 八个场景

| 场景 | 讲解重点 |
| --- | --- |
| 危险动作与鼓励模仿 | 同一事件的支持证据成立，标注关注 |
| 安全警示语境 | 危险画面不自动等于鼓励模仿 |
| 警示与模型判断冲突 | 模拟模型错误回答鼓励，显式警示使结论保持冲突、转人工 |
| 跨事件误关联 | 模拟高置信度错误关联，事件结构约束否决该判断 |
| 屏幕文字隐私暴露 | 单模态证据、时间定位与遮挡整改 |
| 营销及资质声称 | 将资质真实性交给外部核验 |
| 观察不完整 | 保留补充观察处置，不把缺失输入解释为安全 |
| 普通宠物日常 | 没有风险线索时仍保留人工发布复核边界 |

建议三分钟演示顺序：危险诱导结论概览 → 警示冲突的问题与证据 → 隐私整改建议 → 攻防图 → 离线 HTML 报告。点击同一页面的四个标签页切换内容。

## 复现（PowerShell，分别使用三个终端）

后端使用单独的演示数据库，避免混入原有审核记录。在 `backend` 目录运行：

```powershell
$env:VIDEOGUARD_DB = Join-Path (Get-Location) 'data/demo-capture/demo.db'
.venv/Scripts/python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --ws none
```

在 `frontend` 目录运行生产前端；不要为这套演示使用带热更新连接的开发服务器：

```powershell
npm run build
npm run start -- --hostname 127.0.0.1 --port 5173
```

在 `backend` 目录运行静态报告服务：

```powershell
.venv/Scripts/python.exe -m http.server 8765 --bind 127.0.0.1 --directory reports
```

第四个终端在项目根目录执行截图与报告导出（只用 Python 标准库）：

```powershell
python -X utf8 backend/fixtures/capture_demo.py
```

Chrome 不在默认安装位置时传入 `--browser "完整路径/chrome.exe"`。可通过 `--ui`、`--api`、`--reports` 覆盖 HTTP/HTTPS 地址。
脚本会重新建立 8 条演示记录并覆盖生成文件；`manifest.json` 中的审核链接只对保存了对应记录的本地数据库有效，离线 HTML 不依赖数据库。

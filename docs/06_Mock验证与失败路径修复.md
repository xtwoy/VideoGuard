# Mock 验证与失败路径修复

日期：2026-10-14。范围：修复失败处理、补 Mock 回归、固定相同输入比较有/无 PEAD。
本次不调用真实模型，不新增桌面客户端，不改变现有前端架构。

## 先看什么

- `backend/reports/mock-pead-comparison.md`：可直接阅读的场景对照与局限。
- 同名 `.json`：逐条结果、输入哈希、参数和代码哈希；`.csv`：场景表。
- `backend/reports/mock-pead-inputs.json`：冻结的合成解析、定位和关系回答。
- `backend/fixtures/compare_pead.py`：实际执行两个分支并输出报告的脚本。
- `backend/tests/test_locator_failures.py` 与 `test_mock_comparison.py`：新增边界与对照守护。

## 修复前后

| 输入或运行情况 | 修复前 | 修复后 |
|---|---|---|
| 定位响应没有 `answers` 或只返回部分答案 | 被忽略的回答可能形成空线索与可发布结论 | 必须完整匹配问题 ID，否则抛出错误；HTTP 层保存 ERROR，返回 502 |
| 定位回答类型错误、概率为布尔/非数/非有限/越界 | 可能静默跳过或错误接受 | 整个定位响应校验失败 |
| 完整回答全部为合法否定 | 空线索 | 仍为合法空线索，不误报服务失败 |
| 定位线索超过协议上限 | 截断到 80 条 | 明确失败，不能截断后放行 |
| 提供方改变答案对象的排序 | cue ID 可能变化 | 按请求问题顺序生成，稳定可复现 |
| 可选关系服务空回包或缺项 | 可能标为 LIVE，尽管内部已转复核 | 标记 INVALID_OUTPUT/API_FAILED，采用保守降级 |
| `python -O` 运行关系解析 | `assert` 类型/概率校验被删除 | 使用显式校验，优化模式仍拒绝非法回答 |
| 报告回包非法 | 本地报告回退 | 保持显式 FALLBACK_INVALID_OUTPUT 并增加校验回归 |

真实路径仍要求视频解析和问题定位服务配置。只有关系核验可选；报告可明确回退到本地规则报告。
直接注入内置 JSON 是 Mock 路径，不代表这些外部接口已成功联调。

## 对照方案

只研究 `R_DANGER_PROMOTION`（危险行为诱导）。复用同一解析、定位和关系回答，两个分支不重新调用 LLM。

无 PEAD 分支使用简单映射；保留协议校验、候选对生成和相同可信门限，对观察不完整、服务缺失、低可信或混合回答也转复核。
有 PEAD 分支使用当前 `assess_joint` 及自研引擎，额外检查证据事件指向和反向语境等约束。
因此这不是“毫无保护的模型”与“完善系统”的比较，也不是“关闭关系 API”等同于关闭 PEAD。

预先声明的处置预期来自合成场景设计，不是视频人工标注。用例和固定基线均可查看与修改；改变基线应重新生成结果，不沿用旧统计。
保留缺失服务、观察不完整与已知错误场景。不得仅挑选 PEAD 成功的结果。
穷举替换关系回答只统计输出差异，不把原始场景预期套用到替换后的每个组合来计算正确率。

当前结果详见自动生成报告。PEAD 能在“证据指向不同事件、关系模型却说鼓励同一动作”的合成场景中转为复核。
“同一事件内有警示、关系模型仍自信答错”仍可能产生 FLAG；本次保留该反例，没有修改算法来掩盖它。

## Mock 能证明什么

它能证明：给定结构化观察与模型回答，程序按约束处理证据、错误和复核，并可复现决策差异。
它不能证明：视频事实描述正确、声音实际被理解、时间戳精准、真实视频误报率降低、API 成本或延迟改善。
全部材料使用 `MOCK_SYNTHETIC` 标记，报告阶段不参与分类结果对照。

## 复现步骤

完整测试先在 `backend` 执行 `uv sync --frozen`，或安装 `requirements.txt`。不填写 `.env` 也可运行 Mock。

Windows：进入 `backend`，运行 `run_mock_checks.cmd`。
Linux/macOS：进入 `backend`，运行 `sh run_mock_checks.sh`。

单独生成对照：`python -m fixtures.compare_pead --write`。
检查已提交输出：`python -m fixtures.compare_pead --check`。
使用 uv 环境时可改为 `uv run --no-sync python ...`。普通 Python 也可执行对照脚本，它只需要标准库与工程源码。

本次修改后的 ZIP 是完整工程源码及 Mock 验证包，仍需安装运行依赖；不含 `.venv`、`node_modules`、API 密钥或平台专属可执行文件。
最新验证结果和前端构建环境限制见 `backend/reports/mock-validation-summary.json`。

# 运行与复现说明

> 供评审复现与团队打包使用。本文描述仓库当前设计；提交前请在最终 commit 的干净环境中重新执行命令，并将实际结果记录到交付验收表。未配置模型服务密钥时，只能验证合成演示与无密钥失败路径。

## 1. 环境要求

- Python 3.11+
- Node.js（以仓库 CI 与锁文件兼容版本为准）
- uv
- ffprobe（由 FFmpeg 提供；真实视频上传路径需要）
- 可运行的桌面浏览器

## 2. 安装与启动

后端：

```bash
cd backend
uv sync --locked --python 3.11
uv run python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

前端另开终端：

```bash
cd frontend
npm ci
npm run dev -- --hostname 127.0.0.1 --port 5173
```

浏览器打开 http://127.0.0.1:5173。本地端口和启动参数以当前仓库配置为准。

## 3. 无模型密钥的演示

在工作台选择“合成场景演示”，运行五个展示案例。此路径用于复现结构化输入经过 PEAD、报告校验、记录保存和报告导出的行为；它不调用真实模型，也没有分析真实视频。

五个展示场景：
1. 天台危险动作与鼓励模仿；
2. 相同动作与明确劝阻；
3. 跨事件的错误关联；
4. 手机屏幕中的身份证照片；
5. 柯基宠物日常负例。

必须将结果称为“合成输入下的系统结果”，不得称为真实视频识别结果。

## 4. 自动化验证

在 backend 目录执行：

```bash
uv run python -m unittest discover -s tests
uv run python -m fixtures.generate --check
uv run python -m fixtures.validate
uv run python -m fixtures.prompt_contract
uv run python -m fixtures.truth_table
uv run python -m fixtures.argumentation_report
uv run python -m fixtures.compare_pead --check
uv run python -m fixtures.argumentation_html --check
```

在 frontend 目录执行：

```bash
npm ci
npm run lint
npm run build
```

如仓库命令因版本调整而变化，以当前脚本实际定义为准。报告中记录运行日期、操作系统、Python/Node 版本、Git commit、每条命令的退出状态；不得将历史提交的测试结果直接写成最终版本的测试结果。

## 5. 真实视频与外部服务

真实视频路径需要在后端配置适用的模型服务端点、模型标识和密钥，并确认素材授权及服务方数据政策。密钥只能放在服务端环境变量中，不得写入前端或提交到版本库。

本项目尚无真实视频标注集上的准确率、误报率、召回率评估。若评审环境未提供密钥，应演示合成场景，并明确说明真实模型链路未在该环境验证。

## 6. 已知限制

- 需要 ffprobe 才能检查真实视频媒体信息。
- 当前定位为单机原型，不是生产级在线审核服务。
- 脱敏是基础防护，不等于匿名化；请勿把未获授权的敏感视频发送给外部服务。
- “未发现某类线索”不等于视频整体安全，也不代表平台必然允许发布。

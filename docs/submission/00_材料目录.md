## 统一事实口径

- 作品：视鉴 VideoGuard-E，定位为短视频内容安全辅助审核原型。
- 核心研究对象：危险行为诱导场景中的证据关联与冲突裁决；PEAD 不应被描述为十类策略均使用同等深度的论证求解。
- 展示数据：5 套人工编写的合成展示场景；另有 18 套工程回归样例。两者用途不同。
- 当前主分支基线：`cd33c87ce0dc470c05fb14e77557172d80e9f8a9`。最终交付前如有代码变化，必须更新此值并重新验证。
- 当前仓库记录：GitHub Actions 在该提交的后端测试和前端类型检查/构建通过；后端测试记录为 249 项。
- 契约检查数字需在定稿前重新运行生成器确认：现有报告中可见 30 项，历史说明曾出现 31 项，不应在未核实前混用。
- 未做真实模型 API 联调，未完成真实视频上的准确率、误报率、召回率评估；合成场景不代表真实识别效果。
- 当前展示截图不是五个场景对应的真实视频帧。攻防机制图来自独立工程 fixture，必须按此标注。

## 推荐工作顺序

1. 确认赛事正式模板、匿名要求、页数/容量限制和最终提交项。
2. 逐份校对本目录内 Markdown，先锁定文字口径。
3. 完成必要的架构图和机制图；前端改版后再重新截 UI。
4. 统一图号、图注、参考来源和版本号。
5. 组合 PDF，检查分页、字体、链接、文件大小与匿名。
6. 从干净环境复现程序包演示，完成最终提交验收。

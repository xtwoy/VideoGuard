# 现场演示脚本（建议 8–10 分钟）

> 所有合成场景均须在界面和讲解中明确标注为合成输入。若现场没有配置真实模型 API，不要声称正在分析真实视频。

## 0:00–1:00｜问题定义

讲解要点：

“多模态模型可以输出风险标签，但动作、话语和字幕同时出现，并不代表它们属于同一事件或共同支持同一风险判断。我们的研究重点是证据关联与冲突裁决，而不是训练一个新的视频感知模型。”

## 1:00–2:00｜总体架构

展示架构图，按顺序说明视频解析、问题定位、关系核验、PEAD、报告生成。指出上游感知可替换，PEAD 负责约束结构化证据的关系与决策。

## 2:00–4:00｜同一动作、不同口播

展示两套天台合成场景：

- 场景 A：相同危险动作，口播为鼓励模仿；
- 场景 B：相同危险动作，口播为明确警示。

强调这是一组人为编写的对照输入，PEAD 和报告校验链路运行真实代码，但不是模型从真实视频识别出的实验结果。

特别说明：场景 B 的“未支持危险行为诱导”不等于危险动作安全，也不等于平台必然允许发布。

## 4:00–6:00｜跨事件错误关联

展示厨房动作与户外骑行分属两个事件、但关系回答错误地把它们关联起来的构造性输入。说明事件作用域冲突如何阻止错误关系直接变成强风险结论，并引导人工复核。

## 6:00–7:30｜报告与证据追溯

展示证据 ID、时间范围、判断、处置、置信度与整改建议。强调“已检查但未发现”与“没有足够信息判断”是不同状态。

## 7:30–9:00｜验证与边界

简要展示 64 组真值表、论证攻防报告和自动化测试。明确指出：

- 当前验证使用冻结的合成上游输入；
- 尚未完成真实模型 API 联调；
- 没有真实视频人工标注的准确率/误报率/召回率；
- PEAD 的专项论证实验集中在危险行为诱导策略，其他策略深度不同。

## 9:00–10:00｜总结

“本作品的贡献是让审核系统对证据的来源、作用域、关系和不确定性作显式约束，使错误关联更容易被发现、解释并转交人工核查。当前结果证明的是指定输入下的机制行为与工程可复现性，真实视频效果仍需进一步评估。”

# 提交清单与 LLM 润色说明（本文件不提交）

`docs/submission/` 只保留正文源稿与本清单。**01—04 为本次分别提交的四份作品材料；05 为随程序准备的运行说明，可作为“其他文档”提交。** 当前均为 Markdown 源稿，润色定稿后分别排版导出 PDF。

## 一、需要润色和提交的文档

| 文件 | 提交安排 | 文档职责 | 润色重点 |
|---|---|---|---|
| [01_作品简介.md](01_作品简介.md) | **提交：作品简介** | 背景、目标、方案概览、应用价值 | 精炼、突出核心问题，让评委快速理解作品 |
| [02_设计方案.md](02_设计方案.md) | **提交：设计方案** | 架构、数据流、PEAD、规则与工程实现 | 层次清楚，说明设计选择与实现依据 |
| [03_作品测试与分析.md](03_作品测试与分析.md) | **提交：测试报告** | 冻结输入实验、对照、机制与工程测试、结果分析 | 方法与结论对应，准确解释各组数据 |
| [04_创新性说明.md](04_创新性说明.md) | **提交：其他文档中的创新性说明** | 三项设计贡献、与直接做法的区别及验证依据 | 突出具体贡献，避免空泛创新口号 |
| [05_运行与复现说明.md](05_运行与复现说明.md) | **随程序交付；按需作为其他文档提交** | 安装、启动、配置、验证与故障排查 | 指令明确，技术命令与参数保持原样 |

建议先将本清单与 01—04 一起交给 LLM，使其了解材料分工，再逐份润色。05 单独处理，避免将操作说明混入作品论证。

四份核心材料各自独立成文，分别保留标题、章节和本文件内的图号。**不要再次合成一份五章报告，也不要将同一份合订稿重复提交。**

## 四、润色时必须保留的事实

| 项目 | 当前记录与解释 |
|---|---|
| 核心方向 | 短视频内容安全，重点为危险行为诱导的事件级证据关联与冲突裁决 |
| 方法 | 按测试目标预先构造并冻结上游结构化输入；同一用例的有、无 PEAD 分支共享输入及哈希，实际执行 PEAD 与校验代码 |
| 样例规模 | 18 套工程回归样例；5 套冻结展示样例，两者不可混计 |
| 关系穷举 | 7 个含候选对用例，共 64 种关系回答组合 |
| 同输入对照 | 10 个场景；无 PEAD 8/10、有 PEAD 10/10 符合预设处置预期，不能写成真实视频准确率 |
| 处置差异 | 10 个对照场景中 2 个处置桶不同；64 组关系回答组合中 17 组不同，差异数不等于改善量 |
| 机制与工程记录 | 4 类论证攻防形态、31 项契约静态检查、249 项后端测试；保留各自验证范围和版本依据 |
| 创新范围 | 三项领域设计贡献；不将 Dung 论证语义、PyArg、NetworkX 或一般测试流程写为团队首创 |
| 已完成的源码交付检查 | 独立源码包的锁定依赖安装、前端类型检查与构建、后端接口与视频校验、38 项独立核心回归；不与历史 249 项测试合并计数 |
| 尚未完成 | 真实上游 API 联调、独立标注的真实视频效果评估、独立可执行分发验收及最终 PDF；不能润色成已完成 |

A/B 对照必须保留醒目说明：**“两组动作画面相同，变化的是后续口播。”** A 为鼓励模仿，B 为明确劝阻；B 不支持“危险行为诱导”，不等于动作本身安全。不要向图片加字幕、改变案例结果或将后续口播写成动作发生时的字幕。

设计方案和测试报告的图片保留原路径，图片位于 `docs/assets/submission/` 与 `docs/assets/demo/`。仅润色文字时无需重画；需要核对图文时可另外提供对应图片。

```text
请润色我提供的“视鉴 VideoGuard-E”创意作品赛材料，使语言正式、精炼、连贯，适合评委阅读。

材料分为作品简介、设计方案、作品测试与分析、创新性说明四份独立文档；运行与复现说明另外随程序准备。保持各自职责与独立结构，减少重复，不合并成总报告，不添加附录、交接说明或内部文件入口。

只优化表达和论证组织，不增加未经验证的功能、实验、数据、文献或完成状态。保留原稿的测试数字、术语、枚举、代码命令、引用、图片路径和图号；压缩段落时同步检查交叉引用。保留第三方贡献归属，不宣称首创既有论证语义或开源组件。

准确说明实验采用按目标构造并冻结的上游结构化输入，通过同输入对照控制变量，PEAD 及校验由程序实际执行。方法与验证范围集中说明，不在图注中反复加入“合成、Mock”等解释；同时不得改写成真实视频端到端识别实验，也不得将 8/10、10/10 的处置预期符合数写为准确率或泛化提升。17 组处置差异也不等于改善量。

保留 A/B 对照中“同一动作画面、不同后续口播”的醒目解释，区分鼓励与劝阻，不加图片字幕；不支持危险行为诱导，不表示动作安全。

正文保持匿名。不要编造团队、学校、导师、签名、日期或参考文献。遇到事实不清或需要新增实验之处，在正文外单独列为待核实事项，不能自行补写成事实。

请逐份输出润色后的完整 Markdown 正文，再简要列出主要调整和待核实事项。不要将这些编辑说明写入作品正文。
```

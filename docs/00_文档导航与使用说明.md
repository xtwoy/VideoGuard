## 项目一句话

**视鉴 VideoGuard-E：面向短视频的内容安全辅助审核系统，以视频解析、关系判断和自主PEAD规则引擎形成可回溯结论，再输出理由和修改建议。**

## 当前一条主线（不新增架构）

```text
浏览器上传视频
  → FastAPI 接收与校验
  → 视频解析：提取完整时间线、事件和风险线索
  → 问题定位：真实路径必需，从既有事实提取线索
  → 关系判断：可选，判断同一事件的鼓励/警示/无关语义
  → 自研 PEAD：证据关联、规则判断、冲突处理及人工复核分流
  → 问题汇总：根据已引用证据形成原因和编辑建议
  → SQLite（一张 reviews 表）持久化
  → 前端展示 + 导出可独立打开的HTML报告
```

**名称约定：** 外部能力只按职责命名，不能写死供应商或模型名；团队自研模块名称是PEAD。

## 事实口径

- **已具备并经过本地测试：** Next.js 16 / React 19 / TypeScript / Tailwind CSS 4 前端、FastAPI接口、6MB视频上传边界、ffprobe时长校验、v2 解析协议、PEAD离线处理、关系判断/问题汇总模拟回包、SQLite存储、独立HTML报告、后端单元测试、前端严格类型检查和生产构建。
- **已实现适配代码但未经真实API联调：** 视频解析、关系判断和问题汇总服务。
- **尚无数据支撑：** “误报率下降”“召回率提高”“关系判断优于基线”“达到比赛获奖水平”。这些必须靠实验决定。
- **伦理边界：** 视频里的疑似危险内容、职业资质声称或个人信息线索不能直接等同违法认定，最终需要审核人员判断。

## 本版对既有工程的处理

- **不重新搭架构，不拆微服务，不训练视频模型。**
- 仅补充项目需要的可讨论、可执行、可验收的文字说明。
- 系统输出的**HTML审核报告**属于软件功能；这和本次用户明确不需要的**比赛作品报告**不是同一件事。
